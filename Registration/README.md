Project Title: *Student Course Registration System*

Develop a Java console application that allows a school administrator to manage students, courses, and course registration.

*Functional Requirements:*
Your program should be able to:

1. Add Student
Each student should have:
Student ID
Name
Department
2. Add Course
Each course should have:
Course Code
Course Title
Course Unit
course id
3. Register Course for Student
The system should:
Register a student for a course
Prevent duplicate registration
Display appropriate error messages where necessary
4. View Data
The system should allow the admin to:
View all students
View all courses
View courses registered by a student

*Technical Requirements*
Students must make proper use of:
Classes and Objects
Constructors
Encapsulation
Methods
Exception Handling
Collections (ArrayList, HashMap, HashSet, etc.)

The program must be:
Menu-driven and Console-based

*Suggested Classes*

Student
Course
RegistrationSystem
You may add more classes if necessary
